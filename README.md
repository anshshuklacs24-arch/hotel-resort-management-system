# 🏨 Hotel and Resort Management System

A front-end **Hotel and Resort Management System** designed to provide a clean and user-friendly interface for browsing hotel services, rooms, facilities, and booking-related information.

This project is developed using **HTML and CSS only** and focuses on creating a responsive and visually appealing hotel/resort website interface.

---

## 📌 Project Overview

The **Hotel and Resort Management System** is a static front-end web project that represents a modern hotel and resort website.

It allows users to explore different sections such as:

* Home
* About the Hotel
* Rooms & Suites
* Services
* Facilities
* Gallery
* Booking Section
* Contact Information

The project demonstrates the use of **HTML for website structure** and **CSS for styling and layout**.

---

## 🎯 Objectives

The main objectives of this project are:

* To design a professional hotel and resort website.
* To create an attractive and easy-to-use user interface.
* To display hotel rooms, services, and facilities clearly.
* To practice HTML and CSS concepts.
* To understand webpage structure, layouts, navigation, and styling.
* To create a foundation that can later be extended into a complete hotel management system.

This project currently uses **HTML and CSS only**.

There is no:

* JavaScript
* Database
* Backend server
* Login authentication
* Real-time booking system
* Payment gateway

## ✨ Features

### 🏠 Home Page

* Hotel/resort introduction
* Navigation menu
* Attractive hero section
* Call-to-action sections

### 🛏️ Rooms & Suites

* Display of available room types
* Room descriptions
* Room images
* Pricing/information sections

### 🍽️ Services

Information about hotel services such as:

* Restaurant
* Room service
* Swimming pool
* Spa
* Wi-Fi
* Parking

### 🏖️ Facilities

Displays the major facilities provided by the hotel/resort.

### 🖼️ Gallery

A visual section for displaying hotel and resort images.

### 📅 Booking Section

A front-end booking form/interface where users can enter booking-related information.

> Note: Since this project uses only HTML and CSS, the booking form is a **static interface** and does not process actual reservations.

### 📞 Contact Section

Contains basic contact and location information.
