# 🏨 Hotel & Resort Management System

## 📌 About the Project
The Hotel & Resort Management System is a website developed using HTML, CSS, and JavaScript. It provides information about hotel rooms, services, gallery, booking, and contact details.

The main purpose of this project is to create a simple and user-friendly website for a hotel or resort.

## 🎯 Objectives
- Display hotel rooms and their details.
- Show hotel services and facilities.
- Display hotel images in a gallery.
- Provide booking and contact interfaces.
- Create an attractive and easy-to-use website.

## 🛠️ Technologies Used
- **HTML5** — Website structure
- **CSS3** — Styling and page layout
- **JavaScript** — Basic website interactions

## 📂 Project Modules

### 1. Login/Register and Home
Provides the main landing page and login/register interface.

### 2. Rooms and Services
Displays available room information and hotel services. JavaScript adds basic interactions to room buttons and service cards.

### 3. Gallery and Contact
Displays hotel images and contact information.

### 4. Booking and About
Provides the booking interface and information about the hotel.

## ⚙️ JavaScript Features
- Displays a message when a room button is clicked.
- Changes the background colour of a service card when clicked.
- Adds basic interactivity to the website.

## 🚀 How to Run the Project
1. Download or clone this repository.
2. Open the project folder.
3. Locate `index.html` or the main HTML page.
4. Open the file in a web browser.
5. Navigate through the website to explore its pages.
